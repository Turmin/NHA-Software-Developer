# NHA Software Developer

Deze repository is mijn werkmap voor de studie Software Developer. Hierin verzamel ik lesmateriaal, huiswerkopgaven, kleine programmeeroefeningen en praktijkprojecten terwijl ik de opleiding doorloop.

## Studie-onderdelen

De studie is in deze repository verdeeld over negen onderdelen:

- `01 - Programmeren voor Beginners/`
- `02 - Projectmanagement/`
- `03 - Python Gui met Tkinter/`
- `04 - Agile Scrum/`
- `05 - AI Geletterdheid/`
- `06 - Apps Programmeren/`
- `07 - Communicatie en Presentatie/`
- `08 - AVG-Wetgeving/`
- `09 - Software Developer - Praktijkexamen/`

Daarnaast bevat de repository:

- `IJssalon-start/`, een Python/Flask-praktijkopdracht bij de programmeerlessen.
- `Archive187105/`, archiefmateriaal van een vorige opleiding die helaas niet is afgerond en ook niet meer afgerond kon worden.
- `generate-index.js`, een hulpscript dat een eenvoudige `index.html` kan genereren voor mappen die zelf een `index.html` bevatten.

## Leerdoelen

Deze repository laat stap voor stap zien hoe ik werk aan:

- basisbegrippen van programmeren;
- Python-syntax en standaardtypen;
- functies en herbruikbare code;
- foutafhandeling;
- werken met bestanden;
- versiebeheer met Git;
- eenvoudige webontwikkeling met HTML, CSS en Flask;
- voorbereiding op latere modules zoals projectmanagement, Tkinter, Scrum, AI-geletterdheid, apps programmeren, communicatie en AVG.

## Notities

Dit is een studie-repository. De code is bedoeld om te leren, te experimenteren en opdrachten uit te werken. Niet elk bestand is bedoeld als productiecode; sommige bestanden bevatten bewust eenvoudige voorbeelden of tussenstappen uit lessen.
